# Application web (administrateur)

Servie par le backend à la racine du site : aucun serveur à lancer.

| Fichier | Rôle |
|---|---|
| `index.html` | La page unique. |
| `css/style.css` | L'apparence. |
| `js/main.js` | Les pages (une adresse après le `#` = une page). |
| `js/api.js` | Le dialogue avec l'API (jeton ajouté automatiquement). |
| `js/outils.js`, `js/coque.js` | Petits outils et en-tête commun. |
| `js/vues/` | Une page par fichier : connexion, événements, formulaire, lieux, participations. |
| `img/` | Logo et icône. |
